WHAT THIS IS

DGrid AI is an early-stage token on BNB Smart Chain, built with a compliance layer that governs how the token moves between wallets and liquidity pools.

This project is new and experimental. Liquidity is currently small. Anyone considering buying should understand the risks of an early-stage, low-liquidity token before doing so.

HOW TRANSFERS WORK

OPEN
Anyone can buy DGAI from a registered liquidity pool.
OPEN
Anyone can transfer DGAI wallet-to-wallet.
GATED
Only wallets explicitly approved by the project can sell DGAI into a registered pool.
